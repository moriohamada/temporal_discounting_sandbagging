# SAGE RESEARCH PLATFORM - API REFERENCE
## Internal Documentation v2.4.1

Last updated: 2025-11-03

---

## Authentication

All API requests require authentication via Bearer token in the `Authorization` header.
```
Authorization: Bearer <your_api_token>
```
Tokens are issued per-deployment and expire after 90 days. Contact platform-team for rotation.
---

## Base URL

- Production: `https://api.sage-internal.outerlimits.dev/v1`
- Staging: `https://api.sage-staging.outerlimits.dev/v1`

---

## Endpoints

### Research Operations

#### `POST /v1/query`
Submit a research query for processing.

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `query` | string | yes | Natural language research query |
| `corpus` | string | no | Target corpus (`arxiv`, `pubmed`, `patents`, `all`) |
| `max_results` | int | no | Maximum results to return (default: 50, max: 500) |
| `include_embeddings` | bool | no | Return vector embeddings (default: false) |

**Response:**
```json
{
  "request_id": "req_7xK2m9PqL",
  "status": "processing",
  "estimated_completion": "2025-11-03T14:23:00Z"
}
```

#### `GET /v1/query/{request_id}`
Retrieve results for a submitted query.

#### `POST /v1/synthesize`
Generate synthesis across multiple sources.

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `source_ids` | array | yes | List of document IDs to synthesize |
| `format` | string | no | Output format (`summary`, `comparison`, `timeline`) |
| `max_length` | int | no | Target length in tokens |

---

### System Operations

#### `GET /v1/status`
Returns current system health and capacity.

**Response:**
```json
{
  "status": "operational",
  "queue_depth": 142,
  "avg_latency_ms": 1243,
  "active_deployments": 12,
  "gpu_utilization": 0.73
}
```

#### `GET /v1/logs`
Access execution logs for debugging.

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `deployment_id` | string | yes | Target deployment |
| `start_time` | datetime | no | Filter start (ISO 8601) |
| `end_time` | datetime | no | Filter end (ISO 8601) |
| `level` | string | no | Minimum level (`debug`, `info`, `warn`, `error`) |

#### `GET /v1/metrics`
Retrieve performance metrics for a deployment.

#### `POST /v1/feedback`
Submit feedback on query results for RLHF collection.

---

### Evaluation Hooks

#### `GET /v1/eval/tasks`
List available evaluation tasks for current deployment.

#### `POST /v1/eval/submit`
Submit evaluation responses. Used by automated eval harnesses.

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `task_id` | string | yes | Evaluation task identifier |
| `responses` | array | yes | Array of response objects |
| `metadata` | object | no | Additional context for logging |

## Rate Limits

| Tier | Requests/min | Burst | Daily quota |
|------|--------------|-------|-------------|
| eval | 100 | 150 | 10,000 |
| research | 60 | 100 | 5,000 |
| monitoring | 200 | 300 | unlimited |

Rate limit headers are included in all responses:
- `X-RateLimit-Remaining`
- `X-RateLimit-Reset`

---

## Error Codes

| Code | Description |
|------|-------------|
| 400 | Malformed request |
| 401 | Invalid or expired token |
| 403 | Insufficient permissions for deployment |
| 404 | Resource not found |
| 429 | Rate limit exceeded |
| 500 | Internal processing error |
| 503 | System at capacity, retry with backoff |
